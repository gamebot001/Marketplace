# marketplace-documentation/

Documentation for the **Zecians Marketplace** (the platform). Documentation for
the separate Zecians NFT project lives in `zecians-nft-project/docs/`.

Start with:

1. `project_overview.md` — what Zecians is, in plain language
2. `architecture.md` — the Solana service architecture
3. `marketplace_flow.md` — listings, settlement, fees, guards

## Writing pattern

New concept docs use: **WHAT IT IS / WHY WE NEED IT / HOW IT WORKS / HOW IT
CONNECTS TO ZECIANS**.

# Zecians — Project Overview

## What Zecians is

Zecians is a **Solana-native collectible identity project and a
multi-collection NFT marketplace**.

- **The flagship collection:** one-of-one collectible characters, owned as
  Solana assets and independently verifiable.
- **The platform:** the Zecians Marketplace is generic infrastructure where
  other verified Solana projects can register their collections and list
  their own assets.

> **One-sentence pitch:** "Explore Solana collections. Buy, sell and discover
> verified digital assets — starting with the flagship Zecians collection."

## Platform + flagship, in one picture

```
Zecians Marketplace   (platform)
├── Zecians            (flagship collection)
├── Verified Project A (future)
├── Verified Project B (future)
└── Verified Project C (future)
```

Zecians is the platform. The Zecians NFT is the flagship collection.

## What a Zecian is, technically

- A **Solana NFT** using **Metaplex Core** as the primary standard. Metaplex
  is infrastructure; it is not our marketplace.
- Its **art and metadata** are content-addressed with SHA-256 hashes recorded
  in a manifest, and verifiable independently of this website.
- Its **ownership** is read from the chain once the collection is deployed.
  No address or balance is ever invented before deployment.

## The collection

- **Planned supply:** 5,555 total — 5,000 public, 555 treasury reserve.
- **Status:** not generated or minted at scale. Development metadata exists to
  prove the pipeline; no artwork is generated by this phase.
- **Visual identity:** preserved from the existing Zecians design system. The
  art/lore and pipeline now live in the separate Zecians NFT project
  (`~/Desktop/zecians-nft-project`).

## The marketplace

- Listings reference an `asset_address` and `collection_address` — never
  "Zecians" by name.
- Settlement splits the sale price in integer lamports:
  `creator royalty → creator`, `Zecians fee → Treasury`, `remainder → seller`.
- Every service is idempotent by transaction signature. No fake listings,
  sales, volume, or treasury income.
- Fee percentages are configurable and not finalised.

## What Zecians is NOT

- Not an investment product. No profit promises, ever.
- Not a single-collection store. It is a platform for many collections.
- Not a token. No token has launched, no tokenomics exist, no allocations are
  promised.

## Current phase

Phase 1: Solana + multi-collection foundation. Development is on
**solana-devnet**. Mainnet actions, minting, and any token are forbidden until
the owner explicitly approves them. See `launch_plan.md`.
